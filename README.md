# Machine Learning-Based Anomaly Detection System for University Network Traffic

## Project Overview

This graduation project explores the application of Machine Learning techniques to detect anomalous patterns in university network traffic.

The project aims to investigate how data-driven approaches can support network monitoring and help identify unusual traffic behavior.

## Objectives

* Analyze network traffic data.
* Apply Machine Learning techniques for anomaly detection.
* Evaluate the performance of the implemented model.
* Explore the role of Machine Learning in network security.

## Technologies

* Python
* Google Colab
* Machine Learning
* Network Traffic Analysis
